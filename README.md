# Hotel Royal Majestic — Demo Website

A polished, responsive static demo website for Hotel Royal Majestic, Dumka.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Remote Unsplash imagery for the demo

## Included
- Responsive navigation
- Hero section
- Rooms & suites
- Amenities
- Dining
- Location section with Google Maps link
- Click-to-call contact CTA
- Mobile navigation

This is intentionally a demo website. It does not include payments, an admin dashboard, analytics/Search Console setup, or a real booking backend.

## Run locally
Open index.html in a browser, or serve the folder with any static web server.
